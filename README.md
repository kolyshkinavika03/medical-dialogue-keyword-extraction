
# Извлечение ключевых слов из клинических текстов и кластеризация

Учебный NLP-проект по анализу медицинских диалогов. Цель — извлечь ключевые слова из вопросов пациентов и ответов врачей, а также исследовать возможность группировки текстов по тематике.

## Задачи проекта

- Предобработка и анализ клинических текстов.
- Извлечение ключевых слов с помощью **YAKE**, **RAKE** и **TextRank**.
- Визуализация результатов с помощью **WordCloud**.
- Векторизация текстов с использованием **TF-IDF**.
- Экспериментальная кластеризация методами **K-Means** и **DBSCAN**.

## Используемые технологии

- **Python**
- **Pandas**, **NumPy**
- **NLTK**
- **YAKE**, **RAKE**, **TextRank**
- **Scikit-learn**
- **Matplotlib**, **WordCloud**

## Результаты

- Проведено сравнение трёх методов извлечения ключевых слов. **YAKE** показал наиболее содержательные результаты на исследованной выборке, тогда как RAKE и TextRank в текущих настройках чаще выделяли общие или шумовые фразы.
- Для кластеризации использованы **TF-IDF** и два алгоритма: **K-Means** и **DBSCAN**.
- **K-Means** сформировал сильно несбалансированные группы: 1986 из 2000 текстов оказались в одном кластере.
- **DBSCAN** после снижения размерности с помощью **TruncatedSVD** выделил 12 кластеров и 1106 текстов, отнесённых к шуму. При просмотре отдельных групп обнаружились потенциальные тематические направления: боль в груди, стоматологические проблемы, беременность и заболевания мочевыделительной системы.

## Выводы

**YAKE** оказался наиболее подходящим из рассмотренных методов для извлечения ключевых слов на данной выборке.

**DBSCAN** позволил обнаружить отдельные тематические группы, однако значительная доля шумовых объектов и отсутствие эталонной разметки ограничивают интерпретацию результатов.

Возможные направления улучшения:

- Расширение выборки.
- Настройка параметров алгоритмов.
- Очистка шаблонных фраз.
- Использование специализированных медицинских языковых моделей.
